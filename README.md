## 🍛 Culinary Specialties
- **Authentic Pure Vegetarian Feasts (Arati Aaku Bhojanam)**: Temple Pulihora, Gutti Vankaya, home-made podis, pure cow ghee, Bobbatlu, Payasam, and full ceremonial spreads.
- **Royal Non-Vegetarian Banquets**: Slow-cooked Visakha Dum Biryani, Natu Kodi Pulusu, Mutton Sukka, Apollo Fish, Royyala Vepudu.
- **Interactive Live Stalls**: Live Ghee Podi Dosa, Tandoor, Pani Puri & Chaat Counters, Live Bellam Jalebi with Rabri.
- **Celebration Types**: Weddings, Receptions, Gruhapravesam, Sreemantham, Birthdays, Half-Saree functions, and Corporate Banquets.

## 🚀 Key Website Features
- **Festive Aesthetic**: Vibrant, celebratory light-themed design with warm ivory, marigold gold, and royal crimson accents.
- **Full-Screen Parallax**: Each section features high-resolution fixed background imagery with smooth scrolling over images.
- **Custom Section Transitions**: Festive cultural ribbon dividers separating each section smoothly.
- **Royal Banquet Menu Quota**: Interactive banquet menu card (విందు పత్రిక) allowing clients to select course dishes, toggle live counters, adjust guest quotas, and send instant quote requests to WhatsApp.
- **Faithful Contact Section**: Engineered with emerald green & gold curves, floating cloche modal, and authentic feature pills.
- **Persistent Floating Dock**: Instant Call, WhatsApp chat, Menu Quota scroll, and Scroll-to-Top controls pinned at the bottom-right corner.
- **100% Mobile Responsive**: Thumb-zone optimized touch targets and smooth responsive navigation drawer.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript (Vite 8)
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Celebration FX**: Canvas Confetti & custom CSS steam aroma keyframes
- **Deployment**: Vercel ready (`vercel.json`)

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/lunacoderl/svs-catering.git
cd svs-catering

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## 🌐 Deployment on Vercel
This project includes `vercel.json` configured with SPA rewrites. Import the GitHub repository into your Vercel dashboard and deploy with standard Vite settings.
